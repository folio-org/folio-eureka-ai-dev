## What is OAI-PMH

OAI-PMH in FOLIO provides a metadata harvesting endpoint for discovery systems and external aggregators. Configuration is performed in Settings under OAI-PMH, where administrators define endpoint identity, response behavior, and logging controls. The service exports Instance-based metadata and supports format- and policy-dependent output behavior.

## Record Hierarchy / Architecture

```text
OAI-PMH settings
  -> General (service enablement, identity values)
  -> Technical (max records, validation, formatting)
  -> Behavior (deleted/suppressed/error/source policies)
  -> Logs (completed harvest jobs + error download)

Harvest response
  -> Metadata format: marc21 | oai_dc | marc21_withholdings
  -> Source mode: SRS only | Inventory only | mixed
  -> Pagination: max records + resumptionToken
```

## Common Verification Patterns

### Pattern 1: Settings persistence

```text
Action:   Update one OAI-PMH setting and save.
Expected: New value persists after page reload and is used by subsequent OAI-PMH responses.
```

### Pattern 2: Service toggle gating

```text
Action:   Disable OAI service and run a request with a standard OAI-PMH verb.
Expected: Request fails with protocol error behavior regardless of other settings.
```

### Pattern 3: Pagination control

```text
Action:   Set low max records per response and harvest a record set larger than the limit.
Expected: First response is truncated and includes valid resumptionToken for continuation.
```

### Pattern 4: Suppression strategy outcome

```text
Action:   Run harvest once with transfer-suppressed mode and once with skip-suppressed mode.
Expected: Transfer mode includes suppression markers; skip mode excludes suppressed instances.
```

## Key Business Rules for Test Cases

> Jira Phase 3 re-run with corrected project keys returned 0 stories and 0 bugs, so no acceptance-criteria-derived `(jira)` rules were added in this update.

1. Enable OAI service is the global gate; when disabled, all OAI-PMH requests must return error behavior independent of other settings. (cases + source)
2. View and Edit capabilities are separate; View-only users can open settings but cannot persist changes. (cases + source)
3. Logs capability is separate from settings edit capability; edit users cannot access Logs without logs view capability. (cases + source)
4. ListMetadataFormats must expose exactly three supported formats: marc21, oai_dc, marc21_withholdings. (source)
5. Deleted records support controls whether deleted records are represented and how retention is declared (No/Persistent/Transient). (cases + source)
6. Deleted-record detection for MARC-backed content relies on leader position 05 markers used by OAI feed logic. (source)
7. Suppressed records processing has opposite export outcomes: transfer mode includes suppression markers; skip mode omits suppressed instances. (cases + source)
8. When transfer-suppressed mode is used, suppression marker subfield t=1 is expected in exported records for instance/holdings/item mappings. (source)
9. Record source setting determines corpus composition: SRS-only excludes non-MARC inventory records; inventory mode includes generated records; mixed mode combines both. (cases + source)
10. Max records per response controls page size and harvester continuation behavior through resumptionToken. (cases + source)
11. Enable validation introduces schema checking and can fail malformed outputs that would pass when validation is off. (source)
12. Formatted output changes readability/payload formatting only and not business semantics of the response. (source)
13. Error status processing setting affects harvester interoperability expectations for HTTP 200 vs HTTP error codes. (source)
14. Logs retain completed harvest history for 30 days and expose downloadable error detail files only for failed record subsets. (cases + source)
15. Time granularity controls accepted precision for from/until selective harvesting parameters. (source)
16. Base URL must match real endpoint URL; mismatch can break continuation and downstream harvester workflows. (source)
