## What is MARC Authority

The MARC Authority app manages authority records in FOLIO. Authority records establish the authorized form of names, subjects, and controlled terms used by bibliographic records. When an authority heading changes, linked bibliographic fields are updated asynchronously in the background. Authority records are stored in Source Record Storage (SRS) in MARC 21 format.

## Key Terms

| Term | Definition |
|---|---|
| Authority record | Establishes the authorized form of a name, subject, title, or related controlled term |
| Authorized access point | The heading from the non-repeatable 1XX field |
| Reference | A 4XX (See from) or 5XX (See also from) entry that points to the authorized heading |
| Authority source | The authority file the record belongs to (for example LCNAF, MeSH), configured in Settings |
| Number of titles | Count of linked bibliographic records controlled by the authority |

## Record Hierarchy / Architecture

```text
Authority File (settings source, HRID prefix)
      -> Authority Record (UUID, HRID)
                  -> MARC Fields (LDR, 001, 010, 1XX, 4XX/5XX, 999 ff)
                              -> Linked Bib Fields (via $0 and system-managed $9)
```

## Lifecycle / Workflow

```text
Create (quickMARC or Data Import)
      -> Save (quickMARC validations apply only in quickMARC)
      -> Async propagation to linked bib fields
      -> Search/Browse/Export
      -> Delete (soft: LDR 05='d')
      -> Purge window (default ~7 days)
      -> Hard delete (record not found)
```

| Status | Description |
|---|---|
| Active | Record exists and can be used for normal search/export/linking |
| Set for deletion | Soft-deleted in UI, still retained in SRS purge window |
| Purged | Permanently removed from SRS |
