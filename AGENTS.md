## Repo Rules

- This repository uses docs-only role presets for skill installation.
- Any new, renamed, or removed skill under `skills/` must update the role-based install commands in `README.md` and any relevant onboarding docs, or explicitly document why that skill is excluded.
- `skill-feedback` must remain in every role preset.
- Do not add `skills.sh.json`, Claude plugin manifests, or separate role-specific repos unless explicitly requested.
- Future init or context skills are not included in role presets until they exist.
